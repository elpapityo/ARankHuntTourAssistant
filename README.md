# A-Rank Hunt Tour Assistant v0.1.1

日本語名：**Aモブハントツアー補助ツール**

Aモブハントツアーの探索・記録・MAP共有を補助するDalamudプラグインです。

## 主な機能
- 対象エリア：漆黒 / 暁月 / 黄金
- データセンター → ワールド → 追加ディスク → MAP の順で選択
- JP DC：Elemental / Gaia / Mana / Meteor
- Aモブ候補地点の巡回探索
- モブ単位巡回 / 最寄り座標巡回
- 追加ディスク内MAP巡回 / 選択DC内ワールド巡回
- Aモブ発見時の探索記録
- プラグイン有効中のAモブ討伐記録
- 探索・討伐・MOBハント記録へインスタンス番号を保存・表示
- 同じMAP / 同じAモブでもインスタンスが違えば別記録として保存
- 記録クリックでチャット入力欄へ `インスタンス2 MOB名 (X,Y) <flag>` の形式で入力
- 探索記録からMOBハント用リストへ手動追加
- MOBハント用リストの手動並び替え・個別削除・一括クリア
- スキップ記録 / 自動スキップ
- 記録データの保存先設定
- 複数インスタンスがあるMAPを順番に巡回するオプション

## v0.1.1 のインスタンス巡回
設定の「複数インスタンスがある場合は全て巡回する」を有効にすると、選択中の1MAPを巡回し終えた後、Lifestreamを利用して未巡回インスタンスへ移動し、同じMAPを再巡回します。

安全確認のため、v0.1.1ではこの機能を**選択中の1MAPのみ**に限定しています。「追加ディスク内の全MAP巡回」「ワールド巡回」とは同時に使用しません。

現在のインスタンス番号はDalamudのクライアント状態から取得します。自動切替だけLifestreamを使用します。

Lifestreamが対象MAPのインスタンス数をまだ取得していない場合は、推測で切り替えず安全に停止します。その場合は対象エーテライトでインスタンス選択を一度開き、Lifestreamにインスタンス数を認識させてから再実行してください。

## コマンド
`/arankhunttour`

## 必要プラグイン
- vnavmesh
- Lifestream（インスタンス自動巡回・既存の移動処理で使用）

## ビルド
`build.bat` を実行してください。

成功時は次を自動作成します。
- `release\ARankHuntTourAssistant\`：配布ファイル
- `release\ARankHuntTourAssistant_v0.1.1.zip`：GitHub Release等に添付する配布ZIP
- `Z:\ARankHuntTourAssistant\Current\`：実機テスト用コピー

ビルド成功・失敗のどちらでも画面は自動で閉じません。

## 公開前の確認
このソースは、ローカルビルドとゲーム内実機確認を行ってから公開してください。
特に以下を確認してください。
- 通常の1MAP巡回が従来どおり動く
- 探索記録に正しいインスタンス番号が付く
- 同じAモブを別インスタンスで記録できる
- 複数インスタンス巡回が次のインスタンスへ移動する
- 全インスタンス終了後に停止する
- Lifestreamがインスタンス数を未取得の場合、安全に停止して案内が表示される
